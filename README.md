# weteachleague.github.io

Home page for the We Teach League GitHub organization, served at https://weteachleague.github.io. It links to:

- [We Teach League](https://weteachleague.com/) — main site
- [WTL Championship](https://weteachleague.github.io/WTL-Championship/)
- [WTL Prep](https://weteachleague.github.io/WTL-Prep/) — tier lists and draft practice

Static page (one `index.html`), styled like the other WTL sites. To add a site, copy one of the cards in `index.html`.
